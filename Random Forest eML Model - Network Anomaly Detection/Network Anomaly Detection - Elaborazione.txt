2. Download e Gestione Dataset
Script per il recupero automatico del dataset NSL-KDD e la sua preparazione locale.

Python
# Download e estrazione del dataset (da eseguire in Python)
import requests, zipfile, io
url = "https://academy.hackthebox.com/storage/modules/292/KDD_dataset.zip"
response = requests.get(url)
z = zipfile.ZipFile(io.BytesIO(response.content))
z.extractall('.')
